5. Operaciones vectorizadas optimizadas por el compilador
6. Sin serialización/deserialización de datos entre Python/C


3.3. CONSUMO DE MEMORIA
--------------------------------------------------------------------------------

Estimación de uso de memoria:

C:
- Dataset: 50,000 × 10 × 8 bytes = 4 MB
- MLP weights: (10×20 + 20×10 + 10×5) × 8 bytes = 3,200 bytes ≈ 3 KB
- Activations/gradients: ~100 KB
- Total: ~4.1 MB

Python (Scikit-learn):
- Dataset: ~4 MB (similar)
- Overhead de objetos Python: ~50-100 MB
- Total: ~54-104 MB

Python (TensorFlow):
- Similar a Scikit-learn pero con overhead adicional del grafo computacional
- Total: ~100-200 MB

VENTAJA: C usa 10-50x menos memoria que frameworks de Python
